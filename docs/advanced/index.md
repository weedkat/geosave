# Advanced workflows

Combine the operations you need for a larger task. Each guide states its
inputs and result; use them in your own scripts, notebooks or applications.

| Task | Guide |
| --- | --- |
| Find imagery for an area and date | [Download imagery](download-imagery.md), [STAC search](stac.md) |
| Compare vegetation across polygons | [Vegetation by area](vegetation-zones.md) |
| Prepare files and match grids | [Crop imagery](crop-imagery.md), [align rasters](align-rasters.md) |
| Organize dated observations | [Raster catalogs](raster-catalog.md) |
| Work with more pixels than memory | [Lazy processing](large-data.md) |
| Read overlapping image/label samples | [Training chips](overlapping-chips.md) |
| Compose or fine-tune a model | [Model composition](models.md), [pretrained encoders](pretrained.md) |
| Prepare inputs and run a training workspace | [Model inputs](model-inputs.md), [training](training.md) |
| Save and run a trained model | [Model releases](release.md) |

For the rules behind these operations, use [Concepts](../concepts/index.md).

[MLOps](../mlops/index.md).
