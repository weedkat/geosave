metadata; Tiler's callable reader slices the xarray source before NumPy
conversion. Flat indexing supports map-style DataLoader use, with `key(index)`
for prediction identity. Existing tuple access and keyed iteration remain useful
for merging. Native boundary behavior is unchanged.
