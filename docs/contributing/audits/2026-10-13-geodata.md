## Actual data flow

`open_raster` resolves stored pixels and native coordinates. `raster` / `array`
construct xarray objects directly; `stack` owns only a flat DataTree grid-sharing
invariant. Registered `gs` accessors compose owner-local metadata, transforms,
persistence and display, while pandas registration selects a `GeoCatalog` only
for Item-shaped frames. Metadata parsing reads dtype/attrs, not pixels.

The seven Pydantic attr groups connect xarray's plain attrs to CF/GDAL/STAC.
`attrs.combine_attrs` is called by native xarray concatenation/merging; `shared`
collapses only metadata shared by bands. `Nodata.held_by` rounds float fills to
stored precision; Legend codes must fit exactly. These checks are live domain
invariants, not leftovers to simplify away.

Transform modules call native ODC, xarray CF codecs and rasterio operations.
Reprojection, conversion, resampling and materialization remain explicit.
Spectral indices decode selected measurement bands; cloud masks consume the
prepared values their callers supply. Dask spatial mapping is shared by three
real kernels. Visualization computes the pixels required to render and restores
the selected HoloViews backend. Original-file benchmark downloading is independent
of catalog construction and model training.

## Retained problems with smoke evidence

1. **Month-end temporal coverage:** reducing two observations on January 1
   and January 31 with `temporal.resample(..., "ME")` produces the January 31
   label, but `monthly.gs.timespan` reports December 31 through January 30.
   `TimeSpec.bounds` subtracts a calendar offset from an end label without
   accounting for pandas' end-period inclusive day. The start-month control
   reports January 1 through January 31. Bounds tests currently encode the
   former arithmetic; retain and flag an end-to-end resample/anchor/STAC
   coverage decision instead of deleting tested live code.
2. **Identity packing warning:**
   `attrs.combine_attrs([{"scale_factor": 1.0}, {"scale_factor": 1.0}])` returns `{}`
   and emits `DroppedAttrsWarning` claiming the sources differ. Pydantic omits
   defaults from the serialized group, so the post-join spelling check cannot
   recognize a retained identity group. Keep default omission and flag a
   warning bookkeeping fix with identity scale/offset controls.

Both findings go into root `TODO.txt`. They do not establish unused old design.
